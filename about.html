About Sanitization & Health Portal

Developed as an academic Computer Science & Engineering (CSE) web development mini-project demonstrating modern frontend technology, responsive UI/UX, and client-side storage.

Project Mission & Objectives

To empower students, families, and communities with clear, accessible, and actionable health education to reduce preventable hygiene-related illnesses.

  • Interactive Quiz Engine: Self-assessment tool with real-time scoring.
  • Daily Rotator & Favorites: LocalStorage tip bookmarking system.
  • Responsive Design: Optimized for smartphones, tablets, and desktops.

Technical Architecture

Built strictly with standard web technologies following clean code principles for demonstration and viva presentation.

HTML5 Semantic Elements CSS3 Variables & Flex/Grid Vanilla ES6 JavaScript Browser LocalStorage API Font Awesome 6 Icons
